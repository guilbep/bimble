Generated by `node ccore/tools/frames.mjs` (ticket 3D1, ADR 0078); never edit by hand. Raw numbers in
`ccore/out/frames/frames.json` (not committed).

Machine: linux 7.2.11-14-1-ARCH arm64, 8 CPUs (unknown), 15.2 GB. Run 2026-11-26T13:28Z, label `after 3D2 (1, 2, 3, 5): proxies, first frame, occlusion off`, 1-minute load at each model's start: large/wasm 3.45, large/native 5.91, heavy/wasm 6.3, heavy/native 6.35.

Headless Chromium draws WebGL2 with **SwiftShader** (on the CPU, 1280×800): the numbers compare before and
after on this machine; a GPU draws the same frames many times faster. Method in the tool's header: open →
first frame from the navigation start; an orbit of 120 frames over 360°, each drawn as a moving frame and
finished (a 1×1 `readPixels`); the still frame (the full picture) after it; triangles and draw calls submitted
by that frame; the same orbit at a fifth of the fitted distance (close: what culling can leave out); GPU bytes of the model's buffers; JS heap used after a garbage collection; the core module's memory
(wasm build); 60 drag moves streamed at 60 Hz by CDP input (each pointermove → the first frame drawn after it, ADR 0074)
and the canvas's non-background pixels while dragging against the still picture's; 5 clicks on the
model (pointerdown → the frame that drew the selection).
