# Research: a printed scale model of a building

_20 Nov 2026. SEARCH station (Sonnet), checked by the orchestrator. "Opened" means the page was read.
"Snippet" means only a search result summary was seen. "Inference" is our reading, not a source._

## What Bimble has today

- No mesh export exists: no STL, 3MF, OBJ or glTF in `crates/` (code study, 20 Nov).
- Booleans go through manifold. In the browser, `web/manifold-bridge.js` rejects operands that are not
  closed solids. Inference: cut results are closed. Plain extrusions are probably closed. Imported
  `Generator::Mesh` elements are not guaranteed closed (`crates/bimble-core/src/model.rs`).

## Format

- 3MF (opened, https://github.com/3MFConsortium/spec_core/blob/master/3MF%20Core%20Specification.md):
  the unit is declared in the file, millimetre by default. One file holds many objects. Every edge
  must be shared by exactly two triangles, with outward normals. Display colour is for rendering
  only. Print colour needs the Materials extension.
- STL has no unit and no colour. Every slicer reads it.
- Inference: 3MF first (units, objects per storey, the closed-mesh rule is in the specification), STL
  as the fallback.
- Rust crates (opened, crates.io API): `threemf` 0.8.1, 0BSD, published 2026-10-20 (write support not
  checked). `stl_io` 0.11.0, MIT, reads and writes. Inference: 3MF is a zip of XML, so a small own
  writer is also possible.

## Scale-model rules (snippets, vendor and university pages, no standards body)

- A 150 mm wall is 1.5 mm at 1:100 and 0.75 mm at 1:200.
- Minimum wall: FDM 0.8 mm (1.2 mm recommended), resin 0.5 mm (0.8 mm recommended). The University of
  Melbourne NExT Lab says 2 mm for all geometry.
- Sources: https://ritn3d-website.pages.dev/blog/prepare-stl-files-architectural-models,
  https://ms-kb.msd.unimelb.edu.au/next-lab/3d-printing/design-guidelines,
  https://jlc3dp.com/help/article/3d-printing-design-guideline.
- Inference: at 1:200 and smaller, walls and slabs are below the minimum, so the export needs a
  "thicken to the minimum" step. Splitting by storey and supports: no source found.

## How others do it (snippets)

- Revit: built-in STL export. Users report non-manifold output (one report: 16 227 non-manifold
  edges).
- Archicad: built-in STL, surfaces only, no solidity check. Touching elements leave gaps.
- SketchUp: the model must be one solid group. The exporter does not reject bad geometry.
- Bonsai: no STL path found (inference: open the IFC in Blender and use its exporter).
- Common pain: the exporters merge nothing, so touching elements stay separate shells.

## manifold

- Opened https://github.com/elalish/manifold: boolean output is guaranteed manifold. Non-manifold
  input returns an error status. `Merge` can repair slightly open meshes. Apache-2.0.
- Inference: union all elements of a storey (or of the building) with manifold, check that the result
  is valid and not empty, then write 3MF. This is the step the incumbents miss.

## Proposal (inference, not decided)

`bimble print model.bimble --scale 200 --min-wall 1.2 --by-storey out.3mf`: mesh, thicken thin
elements, union per storey through manifold, report what was thickened or refused. The same verb
in the API (see the UI architecture note), so an agent can call it.

## Verified (20 Nov, STUDY station, checked by the orchestrator in the crate sources)

- `threemf` 0.8.1 (0BSD) writes 3MF: `threemf::write(writer, model)` (src/write.rs:16). `Model` has
  public `resources.object`, `build.item` and `unit` (millimetre by default). A test program wrote
  two cubes as two objects: 1 132 bytes, `unit="millimeter"` in `3D/model.model`. No validation on
  write. Maintenance not verified; the writer is small (serde, quick-xml, zip), so it is cheap to
  replace.
- `stl_io` 0.11 (MIT) writes binary STL (f32, no unit field). Tested on a cube: 684 bytes.
- Bimble's binding is `manifold-csg` 0.4.1 (Apache-2.0 OR MIT), not `manifold3d`. It has
  `Manifold::batch_union(&[Self])` (src/manifold.rs:798), `status()` (1337), `is_empty()`,
  `genus()`, `volume()`, `decompose()` (946, to find a storey that falls apart into pieces) and
  `to_mesh_f64()` to get the mesh out.
- Today `bimble-geom` unions cutters pairwise (`crates/bimble-geom/src/boolean.rs`, `kernel()`).
  For a storey, `batch_union` is the call to use. Its cost is not measured.
- Booleans run natively only (`cfg(not(target_arch = "wasm32"))`; the browser uses manifold's own
  wasm). So `bimble print` is a CLI and desktop command first.
- No blocker found. Elements that are not closed solids are refused by manifold. The existing
  snap retry (`SEW_MM`) covers some of them.
