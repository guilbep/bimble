# 27 Nov 2026 — ticket NUI3: the native app's surplus, its scene origin, the Linux desktop, CI on lavapipe

Branch `cc/nui3` from `next` 65ee5fa (NUI2 + SHELL1), merged with `next` af6d840 (MEAS2) at 18:51. Choices by Claude under
the owner's delegation ("performance is everything", every optimisation a setting with a good default and an off value),
recorded in ADR 0084's NUI3 amendment. Offscreen on the dev machine (Apple M1 Pro, Asahi, Mesa Honeykrisp), 1492×790 at
scale 2 (the 3D view 2392×1084), other builders running (load 2-9: p95 moves by several ms between runs). The owner's
project's numbers went to the orchestrator only; the synthetic ones are in `ccore/results/native/nui3.md`.

## What happened, in order

- **The surplus, looked at element by element** (`BIMBLE_TILES_SURPLUS=2`): mostly a few huge single meshes whose boxes
  wrap the building, then long diagonal members. Built: each element tested by its own (placed) box with the group's gate
  shared, large merged elements cut in clusters of 512 triangles, a box tested again in pieces (exact, too costly on the
  GPU: off), a loaded leaf hidden last frame tested by its box alone. Truth test 0 missing.
- **Two crashes found while measuring**: the elements-seen read-back copied the size of the frame collected, not of the
  frame recorded (a link added in between: a read past the buffer); the surplus records kept freed tiles.
- **The orchestrator's question on f32 at national coordinates**: the native path is relative to a scene origin, but that
  origin was the first link ready; a small link in a local frame ready first would have put every other link at 155 mm
  steps. Fixed (the origin where most triangles are, moved with the camera when a heavier group arrives) and tested
  (`native_geo_test`: the same picture at 0 and at 2,600 km; it fails on the old code). MEAS2 (merged) made the far measure
  exact: the test's "known" line became a check.
- **The release blocker**: Ubuntu 22.04 has no glslc; the SPIR-V is now committed with a signature per header and a check;
  built in an ubuntu:22.04 container without glslc.
- **CI's `native_app` failing in 0.1 s**: the job's glob missed Mesa 25's `lvp_icd.json`; with the right file lavapipe 25.2
  crashed in the box tests' shader (a read-only storage image); read by a sampler it runs (ubuntu:24.04 container:
  `native_app_test` and `native_geo_test` pass).
- **The Linux list** (`ui/desktop.c`): portal dialogs with the in-app fallback, drops, the title and app id, touchpad pan
  and pinch zoom, Ctrl + wheel, the section box by numbers, a command palette, clipboard calls logged, `desktop/` in the
  archive with an install script.
- **Loading**: exterior first (the cross-link shell attached to the tiles) measured no sooner than the plain order; four
  loader threads instead of two finish sooner with the same frame times.
- **Back faces**: off. Not a convention bug; two causes measured: the rasterizer's tie on silhouettes (8 px or fewer,
  edge-on) and an interaction with the element-level occlusion not yet explained (synthetic links: about 100,000
  element-frames with it, about 140 by tile or without; about 15,000 when only one pass culls).
- **Still frames**: measured where the time goes (CPU recording of tens of thousands of commands, the GPU's millions of
  triangles, a 202 MB page made); pacing, one frame in flight, larger groups, smaller pages, the elements seen at half
  resolution and a ramped still budget did not help. Kept: two pyramid levels a dispatch, and in still frames the
  elements hidden last frame under one gate a leaf (their tests or-ed: one command a run): the still p95 fell on the
  owner's project, still above the line; on the small synthetic sets it rose (few still frames, whole runs drawn).
