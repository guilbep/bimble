## What happened
- **Plan preview**: sheets rasterize through resvg (system fonts), so the preview is the exported drawing.
  `bimble plan … plan.png --dpi 150`; the viewer's Plan window shows the sheet live (zoom, recomputed only
  when a setting changes). Real file #2: PNG in 0.38 s.
- **I4, formwork-style plans** (ADR 0018). Read the office's A2 plans (kept out of the repo) for their
  conventions, then built them as a *plan template* rather than code: title, level note, dimension unit,
  hidden classes, legend words, title-block columns, `{fields}`. French example in `docs/templates/`.
  - Seen below the cut: tops filled lighter, painted from low to high (hidden-line removal by painting).
  - IfcGrid axes from IFC, including IfcIndexedPolyCurve; real file #1 has its grid repeated on 12
    storeys (192 axes → 16). Without grids, axes through the cut columns.
  - Dimension chains (axis to axis, then overall) in cm with architect's ticks: on real file #1 they read
    362 / 362 / 362 / 420.9 / 362 — the spacings on the office's own plan of that building.
  - Terrain (IfcGeographicElement) made the first real plan 104 m wide and too big for A0; now hidden by
    default with rebar, spaces and openings.
  - Sheet texts got anchors, rotation and bold, placed from Helvetica widths so SVG, PDF and PNG agree.
- **I2, history** (ADR 0017): `house.bimble-history/` with content-addressed objects (one per element,
  tree, commit), branches, HEAD; `bimble history init|commit|status|log|diff|branch|switch|merge`.
  Trying a merge on the demo (height changed on one branch, width on the other) showed element-level
  conflicts were too coarse and `--prefer` then dropped one change: merge became field by field.
- **I2, editing in the viewer** (ADR 0019): properties form (name, sizes, origin), move/copy/delete,
  placing columns, beams, walls and slabs by clicking on the storey level, undo/redo (Ctrl+Z/Y), save
  (Ctrl+S), History window (start, commit, branches, switch, merge, log). Checked on the virtual display:
  copy, a size drag, undo, placing a column and a beam. Typing into fields could not be driven there
  (xdotool keys reach shortcuts but not text fields); the form logic is unit-tested instead.

## Later: views and reference plans (ADR 0021)
- Pierre asked, before the next task, for five things with Revit screenshots and a wireframe: edit
  elements in 2D views as in 3D, reference DWG/PDF plans in a view, a properties window, a model
  navigator, and a view range like Revit's. His choices: PDF + DXF (DWG via a converter), views in
  `.bimble` with a side file for IFC, the wireframe's layout, plans and sections now.
- Views are model data (`Model.views`, commands, history, merges); default views are derived from the
  storeys with stable ids. 2D views are the 3D renderer with an orthographic camera and the view range
  as the clip box, so picking, editing and measuring needed no second path. Ceiling plans mirror the
  picture so north stays up (the clip passes needed the other winding when mirrored; test fails
  without it).
- Driven in headless Chrome on the demo with a synthetic DXF (grid, slab edge, 12 columns, one drawn
  80 mm off): the plan shows the reference over the model, the 80 mm column stands out, dragging moved
  the plan by 841 × 560 mm for a 60 × 40 px drag at 14 mm/px, measuring snapped, a column was selected
  and widened to 600 mm in the plan, a section and a ceiling plan opened, an invalid range was refused.
  Desktop on Xvfb with the demo exported to IFC: hiding IfcFooting in a plan, "Save views" and Ctrl+S
  wrote `demo.ifc.bimble-views.json`; reopening applied it.
- Found while looking at the plan:
  - Cut columns lost to the slab they stand on (the column's bottom, seen from inside, is level with
    the slab top), in the picture and when clicking (the footing was selected). Cut surfaces now win
    where they face the camera; picking a solid seen from inside counts its cut surface. Both tests
    fail on the old code. A first try (writing the cut's depth on the box from the shader) broke the
    "all-enclosing box changes nothing" test: back faces then beat their own front faces.
  - The default ceiling-plan cut was halved on every storey (1.5 m on a 3 m storey) instead of only
    where 2.3 m doesn't fit.
  - Reference grid lines vanished when zoomed in (segments were drawn only if an end was on screen).
- Limits: the cut outline of a column standing on a slab is partly hidden (the cut surface is
  darker, so it still reads); the side file can't be read back in a browser; Layouts only opens the
  plan window.
