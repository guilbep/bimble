## What happened, in order

- **The owner's first window** (14:25-14:58, two commits for his binary): SDL's viewport and scissor assertions
  (and one abort) came from ImGui reading the window's size a frame before the swapchain's; every size now comes
  from the texture acquired that frame. An assertion handler logs and continues. Copy also writes the report to a
  file. A local session log (`~/.local/state/bimble/sessions/…`) with a crash handler; then debug files by build
  id and `native/symbolize.sh`. The section box's handles never moved: every press was refused by the core
  ("unknown field: tol_px"); fixed, and the driver now drags handles at scale 1 and 2.
- **Tiles** (renderer_path=tiles): first one GPU object per tile: the CPU recording of thousands of draws cost
  5-45 ms a frame on the owner's project; shared pages and one multi-draw per (pass, page, pipeline) took it to
  0.3-1.5 ms. Every indirect command still costs about 1 µs here (Mesa's multi-draw): pass 1's runs are joined.
- **Occlusion**: two passes on this frame's depth, tile boxes first, then groups of elements (the orchestrator's
  measurement: a tile with one visible element draws all its triangles; the elements with a visible pixel are
  ~1.5 M triangles from outside). The id buffer gives the elements seen; groups not seen are tested on the GPU.
- **The truth test** compares id AND depth buffers: the first version counted coplanar ties (the frame fixture's
  touching faces, whose winner depends on the draw order) as missing; by depth they are ties, not losses.
- **On the owner's project**: every leaf's elements inside its tile's box (8,190 leaves, 0 outside); the truth
  test inside and outside: 0 missing (414 frames). Back-face culling loses elements (the flag or its orientation):
  off.
