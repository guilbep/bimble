## The three audits

The findings, with their evidence and state, are in `docs/research/audit-2026-11-26.md`.

- **A, library layers and file readers.** No memory-safety report in about 4.6 million mutated
  inputs under the sanitizers. Four cases where a small hostile file costs much memory or time
  (a 19 KB binary `.bimble`: 1,243 MB; a 4 KB DXF: minutes; PDF and STEP quadratic cases), one
  size that wraps on wasm32, nine bounds checks with no test. Fixed by FIXLIB. The auditor's own
  parallel fuzzers were probably the trigger of the 04:10 kill.
- **B, host program, session, release and CI.** The access rules hold on every route. One
  critical defect: with `--session`, changes not saved were lost when the host restarted with the
  model path spelt differently. Two high: a branch switch or merge dropped link changes not
  saved, and HEAD moved before the working file was written. Fixed by FIXSES; the release and CI
  findings by FIXDOC. Open: the history stores no `links` section; nothing ran on Windows.
- **C, the lab in a browser, the tests, the claims.** A read-only IFC showed no element property;
  a lost host gave no notice; 7 of 9 README numbers were stale or overstated; the shell graph
  test caught 4 of 9 mutations. Fixed by FIXUI and FIXDOC. Open: the Levels layout at 1280 px and
  the smaller defects listed in the audit file (C7 to C9).
- **After the fixes:** `ccore/ci/run.sh full` on `next` with the four fix tickets merged; the count
  is in `ccore/results/ci.md`.
